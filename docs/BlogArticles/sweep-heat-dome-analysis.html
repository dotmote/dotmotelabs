Making Extreme Heat-Dome Analysis More Scalable with SWEEP

Aji John November 2026

Share:

Extreme heat events are more than a single temperature record. Understanding their impacts can mean working across observations, locations, and analysis steps—and making sure the workflow can be run consistently as the research grows.

A new peer-reviewed study examines an extreme heat-dome event and demonstrates the value of computational workflows for this kind of environmental analysis. Read the published study.

Why workflow orchestration matters

Heat-dome research can involve substantial data and a sequence of processing and analysis tasks. Researchers need to coordinate those tasks, manage the computational work, and be able to repeat the analysis. Handling each step manually can make it harder to scale the work or reproduce it later.

SWEEP is a cloud workflow orchestrator that helps researchers run data-intensive workflows across cloud providers. In this study, SWEEP supported the analysis workflow, helping connect the computational process to the scientific question.

From a complex event to a repeatable workflow

For extreme-event analysis, an orchestrated workflow can make it easier to organize data processing and analytical tasks into a repeatable sequence. That structure helps researchers focus on interpreting the evidence rather than manually coordinating every computational step.

SWEEP is designed to help run workflows at scale while keeping their steps organized. The approach can support research that needs to bring together large or distributed datasets and can make computational methods easier to rerun as new data or questions emerge.
